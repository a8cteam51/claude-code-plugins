# Changelog

## [1.0.0] - 2026-03-25

### Added
- Initial release
- WordPress plugin security review via slug, URL, or local directory
- PHPCS with WordPress security sniffs
- Grep-based scanning for 29 vulnerability signatures (PHP + JS)
- WPScan vulnerability database integration (optional, requires API key)
- NVD CVE database lookup
- WordPress.org API metadata analysis (installs, ratings, reviews, support forum)
- GitHub repository analysis
- Manual code review of AJAX handlers, REST routes, shortcodes, file uploads
- Structured risk report with approve/conditional/reject recommendation
